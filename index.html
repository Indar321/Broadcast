WHAT THIS DOES: pulls keywords from your text automatically, builds a title/caption/tags/board for whichever fields each platform actually uses, and trims every field to that platform's real character limit — always cutting at the last full sentence or word, never mid-word, so the post reads clean. If you type just a short headline instead of full content, it auto-expands that into a complete platform-ready post rather than posting the bare title. If you attach an image it also center-crops a preview to each platform's standard ratio. 100% offline, no AI, no network call, nothing to fail.

WHAT THIS DOESN'T DO YET: actually publish to your accounts or upload video to YouTube. Real posting needs each platform's official developer access connected on a backend — Meta's Graph API (Instagram/Facebook/Threads), the X API, LinkedIn's API, YouTube Data API, Pinterest API, and Reddit's API all require app registration + OAuth login per account. Quora has no public posting API at all — always manual. "MARK AS POSTED" is local tracking only.
